# 决策知识库 · v1（首批交付）

> 硬币知道（the-coin-knows）/ GitHub 引流 / AI 科普视频 三线共用的内容引擎。
> 壳可以换——网页、小程序、仓库、视频都只是形式；人为什么犹豫、在哪犹豫、为什么把决定交给硬币，才是这里存的弹药。

## 八条军规（每张卡的出生证）

1. **人话铁律**：核心思想必须一句大白话讲给外行听懂，讲不顺返工。
2. **溯源铁律**：关键论断必须挂出处（研究者+年份）。挂不出处的删。
3. **真伪分档**：每卡必标——【科学结论】（有实验/数据）/【史实】（有文献可考）/【传说】（附会，但"它如何流传"也是知识）/【机制推导】（推论+共识，直接实验少，如实标注）/【复现危机】（原效应被方法学或重复实验推翻，辟谣卡专用，如卡 19）。
4. **一个思想一个户口**：同一思想只住一张卡，别处只放交叉链接。
5. **三落点**：每卡必带 app 落点 / 视频落点 / 仓库落点，全空不入库。
6. **合规红线**：定位永远是"文化研究 + 科学解释"。不做运势生成、不做占卜收费引导。
7. **问题驱动**：每张新卡必须回答"解决需求清单里的 P 几"，答不上不入库。
8. **批次制**：每批交付必须附自检报告（`_自检报告_*.md`）。
9. **先全文，后蒸馏**（2026-09-29 追加）：批 2 起强制——优先采集原文全文（论文 PDF / 书籍 / 字幕，走既有 8765 采集管线与服务器端阅读器），读完全文再蒸馏，引用精确到章节或段落。摘要级核验只是过渡态：每张卡必须标注核验等级——【已核原文】/【已核摘要】/【待核】，不许装。

## 双轴组织法

- **横轴（场景）**：用户在哪犹豫——五地带，见 `00_总纲_人类犹豫地图.md`
- **纵轴（学科）**：为什么会犹豫——决策心理学 / 概率与随机 / 文化史（严格真伪分档）

新卡先报横轴坐标，再报纵轴学科。
