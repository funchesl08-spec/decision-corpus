# 《五行大义》书卡 · 五行的"官方说明书"：一部在中国失传、靠日本抄本活下来的百科

**核心思想（人话版）**：今天谁都能说两句"金木水火土"，但古代"五行"到底指什么、怎么配四方四季五味五脏，最系统的官方说明书是隋代萧吉这部《五行大义》——四十篇论文把五行的名、体、数、生克、德合、刑害冲破全部定义一遍。它在中国本土失传，**靠日本遣隋使带回的抄本活了下来，清末才回传**——这本书的命，本身就是一个运气故事。

**读原书读到的三件事**：
1. **自封的公理**：序照录——"夫五行者，盖造化之根源，人伦之资始……万有森罗，以五为度，**过其五者，数则变焉**"。世界必须是五份的，超过五就"变"——分类学先于事实，这是五行体系的公理结构（对照卡63：数学外壳的又一例）。
2. **定义的层级**：全书从"释五行名"到"论刑、害、冲破"，是把关系学做成了表格系统——**相生相克只是第一层，德、合、扶抑、刑、害、冲破是六层进阶关系**。术数应用里的复杂断语，源头都在这里。
3. **它是术数的"标准库"**：隋代官方（萧吉官至上仪同）出品的五行定义集，后代八字、六壬、奇门的术语全部调用这套库——**读它等于读术数的 API 文档**。

**真伪分档**：【史实】文本与回流史；【方法论】古典分类学。
