===== 花曆 =====

花历
作者：
程羽文
明
本作品收录于《
说郛续
》
影印本：
。
姊妹计划
:
数据项
花有开落凉燠，不可无历。秘集月令，颇与时舛，予更辑之，以代挈壶之位，数白记红，谁谓山中无历也。
正月
[
编辑
]
兰蕙芳，瑞香烈，樱桃始葩，径草绿，望春初放，百花萌动。
二月
[
编辑
]
桃夭，玉兰解，紫荆繁，杏花饰其靥，梨花溶，李能白。
三月
[
编辑
]
蔷薇蔓，木笔书空，棣萼韡韡，杨入大水为萍，海棠睡，绣球落。
四月
[
编辑
]
牡丹王，芍药相于阶，罂粟满，木香上升，杜鹃归，荼醿香梦。
五月
[
编辑
]
榴花照眼，萱北乡，夜合始交，薝卜有香，锦葵开，山丹頳。
六月
[
编辑
]
桐花馥，菡萏为莲，茉莉来宾，凌霄结，凤仙降于庭，鸡冠环户。
七月
[
编辑
]
葵倾赤，玉簪搔头，紫薇浸月，木槿朝荣，蓼花红，菱花乃实。
八月
[
编辑
]
槐花黄，桂香飘，断肠始娇，白𬞟开，金钱夜落，丁香紫。
九月
[
编辑
]
菊有英，芙蓉冷，汉宫秋老，芰荷化为衣，橙橘登，山药乳。
十月
[
编辑
]
木叶脱，芳草化为薪，苔枯，芦始狄，朝菌歇，花藏不见。
十一月
[
编辑
]
蕉花红，枇杷蕊，松柏秀，蜂蝶蛰，剪彩时行，花信风至。
十二月
[
编辑
]
腊梅坼，茗花发，水仙负水，梅香绽，山茶灼，雪花六出。
