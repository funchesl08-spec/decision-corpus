# coin-knows · 硬币知道（AI 决策辅助技能 · 开源）

> 给选择困难的人一个体面的下台阶：**古人给仪式，科学给依据，我们给出处。**

这是一个**给 AI 用的技能包（Skill）**：把本仓库装载进任何支持 Skills 的 AI 助手（ZCode / Codex / Claude Code 等），之后你只要对 AI 说"我纠结要不要……"，AI 就会按本技能的流程接住你——随机给你结果、古签给你体面、心理学给你依据，并且从不假装自己能预言。

**不开小程序、不上应用商店、不收费、不做任何与焦虑挂钩的设计。**

## 装载方式

**方式一 · ZCode / Codex（本机技能目录）**
```bash
# 克隆仓库后，把技能文件夹拷进技能目录（二选一或都装）
cp -r skill-coin-knows ~/.agents/skills/coin-knows
cp -r skill-coin-knows ~/.codex/skills/coin-knows
```

**方式二 · Claude Code / 其他支持 Skill 规范的 Agent**
```bash
cp -r skill-coin-knows <你的agent技能目录>/coin-knows
```

**方式三 · 任意聊天 AI（通用）**
把 `SKILL.md` 与 `references/models.md` 的内容粘贴进系统提示或对话开头即可——它是纯 Markdown，任何大模型都能照做。

## 它会什么

| 你说 | 它做 |
|---|---|
| "外卖纠结吃什么" | **筒**：帮你删到 5 个以内再抽签 |
| "要不要去参加同学会" | **掷**：先问"你希望是哪面"，落地后问"松了口气还是咯噔" |
| "要不要辞职" | **秤**：不掷随机——两个十年后悔打分＋"没做的事更后悔"研究 |
| "最近好倒霉，帮算算运势" | **测**：运气体检——概率小测验＋古法知识签，明确不预测 |
| "两个 offer 怎么选" | **称**：维度加权账＋锚定/框架防御 |
| "这东西 3000 块值不值" | **押**：时薪换算＋稀缺检测＋30 天冷静期 |
| "我和 TA 还有缘分吗" | 温柔拒答 → 转「秤」 |

每个结果的背后都挂着一条可查证的知识卡（`decision-corpus/cards/`，80 张，全部带核验等级）。

## 签池成分（公示）

关键词粗分：吉 25% · 中 33% · 吉凶混 11% · 凶 32%。三档可选（全真/标准/暖），按场景默认，明示切换——随机在选定池内公平如初。

## 红线（写死在 SKILL.md）

随机不预言 · 只管"两个都行" · 每个结果挂出处 · 凶词转译为行动提示 · 低谷用户优先冷静与援助 · 深夜冲动先记账不执行。
