# 六十四卦结构表（真算引擎 · 变卦计算用）

> 爻位二进制自**初爻到上爻**，1=阳 0=阴。前三位=下卦（内卦），后三位=上卦（外卦）。
> 先天卦数（起卦用）：**乾一 兑二 离三 震四 巽五 坎六 艮七 坤八**。
> 三爻卦二进制（自下而上）：乾`111` 兑`110` 离`101` 震`100` 巽`011` 坎`010` 艮`001` 坤`000`。

## 变卦算法

动爻 n（初=1…上=6）：把本卦二进制第 n 位翻转（1↔0），得到的新六位串在表内查同二进制的卦名，即变卦。64 个二进制串两两不同，查表唯一。

**算例**：风雷益（#42，巽上震下）二进制 `100011`（下震`100`+上巽`011`），上爻（第 6 位）动：1→0 → `100010`，前三位`100`=震不变，后三位`010`=坎 → 上坎下震 = 水雷屯（#3）。查《易林》即「益之屯」。
