# 六模型＋扩展流程详表（coin-knows references）

> 每个流程 = 交互步骤 ＋ 依据原理。依据编号对应知识库卡片（GitHub: funchesl08-spec/decision-corpus → cards/）。

## 掷 · 二选一（都行的小事）

1. 请用户说清 A、B 两个选项。
2. **关键一步**：先问"如果现在抛，你心里希望是哪面？"——让用户说出来或写下来（不进结果计算）。
3. 生成随机（报数法或时间戳，见 SKILL.md）→ 宣布结果。
4. 追问："落地那一刻，松了口气还是咯噔了一下？"——松气＝听硬币；咯噔＝"那还抛什么，你已经选好了"。
5. 三步收尾（先接题·签文落地·人话收尾，见 SKILL.md「输出三步」）。
- **依据**：责任外包（卡03：纠结缺的不是信息，是"不用负全责"的许可）·偏好揭示（卡04：你对某面的期待就是真实偏好）·预期后悔（卡02）。

## 筒 · 多选抽签

1. 收集 3–10 个选项。
2. 超过 5 个先执行**"删三强"**：请用户手动删到 ≤5（选择过载的直接解法是缩小集合，卡01：果酱实验 24→6 种，购买率 3%→30%）。
3. 抽签（报数法）→ 结果。
4. 多人场景启用**群抽**：结果对全员有效，配程序公平文案"吵不出就抽签，抽签永远服众"。
- **依据**：卡01·卡07（随机赠签＝变量奖励，如实标注"我们连上瘾机制都拿来做好事"）。

## 秤 · 做不做（人生级）

1. **不掷随机物。**请用户分别想象"做了"和"没做"十年后的自己，各打一个后悔分（1–10）。
2. 展示研究结论：长期看，人对"没做的事"的后悔显著深于"做错的事"（卡02，Gilovich & Medvec 1995）。
3. 输出倾向提示＋强制冷静剂："这是研究提示，不是答案；这个量级的决定，请和真实的人聊聊。"
- **子模式 弃**（要不要放弃已投入的事）：两栏表——"已投入"一栏、"未来收益与代价"一栏，强制分开算。文案："钱已经花了，别让过去给未来投票。"（卡15 沉没成本）

## 洗 · 顺序

1. 收集待办清单。
2. 随机抽出"第一件"→ 配文案"先做它 15 分钟，之后想换再换"。
3. 附「15 分钟契约」：15 分钟后可换，不扣分。
- **依据**：卡03（随机给起点不给合同）·卡30（目标渐近：开始做之后完成动机自动上升）。

## 测 · 运气体检（最近倒霉/想算运势）

1. **先接情绪**："倒霉是真的，我不否认它。"——然后声明：以下是概率学小测验＋民俗知识签，不预测未来。
2. **记账**：请用户列最近倒霉的 3 件事，再列"本周顺利的 3 件小事"——多数人卡在后一半，当场体感可得性偏差（卡21：不是更倒霉了，是倒霉的更好记）。
3. **曲线**：讲解回归均值——连续低谷后回到平均是统计规律，不是转运，也不需要转运（卡46）。
4. **排雷**（抽签式吐两张卡）：
   - 「连着倒霉≠好运在排队」——独立事件没有账本（卡06 赌徒谬误）
   - 「别人晒的好运≠你更惨」——朋友圈是精选集（卡14 幸存者偏差）
5. **赠签**：随机古签一张（易林吉签优先；王充"幸偶篇"句备用："同日被霜，蔽者不伤"）。
6. 若用户连续多日使用或流露绝望 → 冷静剂＋建议与信任的人聊聊。
- **依据**：卡46·06·21·14·73·76。

## 称 · 重大 A/B（两个 offer/两套房）

1. **不掷随机物。**请用户各自列出两个选项的关键维度（≤5 个）。
2. 给每个维度定权重（1–5）。
3. 两方案逐维度打分 → 算加权总分，展示"差距带"。
4. **防偏提醒**：先定维度再听别人意见（锚定，卡23）；正反两种说法各算一遍（框架，卡24）。
5. 输出："分数是地图不是裁判"——若差距带很窄，说明"其实选哪个都行，那就可以用掷了"。
- **依据**：卡53（结构化决策）·卡23·卡24。

## 押 · 剁手冷静期

1. 用户报商品与价格。
2. 三连：换算时薪（"这个＝你 XX 小时工资"，卡25 心理账户）·稀缺检测（"限时/仅剩 N 件是商家武器"，卡36）·禀赋预警（"加购的那一刻你就舍不得删了"，卡27）。
3. 开**30 天冷静期清单**：记下，30 天后还想要再买。
- **依据**：卡27·36·25。

## 守门员 · 深夜冲动

触发：深夜（22 点后）＋大额下单/辞职信级动作。
1. 不评判，先接住："这个想法先别执行。"
2. 只做一件事：**记下来，明天中午再看**。附一句"深夜的大脑已经连续工作 16 小时了，它说的话不算数"（卡19 决策疲劳·卡44 自我损耗）。
3. 明天还想做，欢迎回来走「秤」。

## 缘 · 缘分体检（批67 用户定稿：缘分可以测）

触发：缘分 / 合不合适 / 他喜欢我吗 / 复合。

1. **接住＋重定义**："缘分可以测，但先说清楚测什么——不是命里有没有，是账上还剩多少。缘分不是天定的，是攒出来的。"
2. **仪式壳给足**：报数 → 传统合签（易林或灵棋，繁体原文＋白话）——想要传统感的，一步不少。
3. **拆穿时刻**："这支签为什么你们俩都觉得准？"——巴纳姆拆解（卡08）。先信后拆，这是本模型的灵魂动作。
4. **行为体检三问**（只问可改变项，不判命）：
   - 最近一次让你俩都笑出声的对话，是多久前？（可得性检查，卡21：你记得的全是他没回的消息）
   - 你们上一次一起做傻事，是什么时候？（关系存款——感情是行为累计的）
   - 那句最想说的话，说了吗？（预期后悔，卡02：没说的话才是长期账单）
5. **台阶输出**："工具给不了'他喜欢你吗'的答案——没人给得了。但这三问你刚才答的时候，心里已经有数了。要递话，现在比抽十支签都管用。"
6. **两条底线**：不输出"复合概率 78%"这类假精确数字（假精确是敌人的武器，不是我们的）；发现控制/贬低/暴力信号 → 跳出仪式直说"这不是缘分问题"，给援助提示。
- **依据**：卡08（先信后拆）·卡21（可得性）·卡02（预期后悔）·卡57/76（仪式壳）。

## 卜 · 古法签房（仪式感旗舰）

1. 用户报一个 1–999 数字 → 模拟十二棋掷灵棋（或直接抽易林）。
2. 出签：繇辞原文（繁体原貌）＋白话＋**知识注**（如"此法出自六朝以前；占准与否四库馆臣也存疑——但作为随机仪式，它很美"，卡57）。
3. 提供**拆穿模式**：同一支签一键切到"巴纳姆拆解"——"为什么你觉得它准？因为诗写的是人共有的处境"（卡08）。
4. 边界尾注同全局。
- **依据**：卡57（灵棋经）·卡76（易林 4096 签）·卡08（巴纳姆）·卡61（择吉标准化梗：'乾隆帮你把假神煞删过一轮'）。


## 仪式规范（全模型通用·批65补丁）

- **签文格式化**：繇辞/引文一律用引用块＋繁体原貌呈现，紧跟白话一行——
  > 南山松柏，長受嘉福。
  > （白话：像南山上的松柏，长久安受福泽。——汉《焦氏易林》）
- **不可再掷**：同一问题重抽请求 = 触发硬纪律 6（这一条是灵棋经原文给我们的："不可再掷，再则无验"，卡57）。仪式感的心理内核就是"不可逆"——可撤销的结果没有安抚力。
- **安放仪式感的位置**：仪式感不在形容词里（"神秘地""仿佛命运般"——禁用），在三个结构动作里：命题确认（祝曰）、用户亲自报数（我掷）、签文留存（收势）。这三个动作全部有依据：卡38 安慰剂仪式研究——仪式感"恢复控制感"是实证效应，我们的仪式是有效的，不是玄的。
- **签文落地（批74，治"无厘头"）**：繇辞/卦辞引用之后，**必须**紧跟"放到你这件事上：……"——用两三句人话把签文翻译进用户的具体处境（给建议、点处境、给台阶皆可）。只上诗句不给落地＝事故，不是风格。


## 实战案例（真测批68 抓到的边角）

**凶签+场景撞车**：测"中午吃什么"抽到易林「早霜晚雪，伤害禾麦。损功弃力，饥无所食。」——凶句直出会吓人，且"饥无所食"撞上吃饭场景近乎黑色幽默。
**标准处理**：①转译（"古人把'天时不配合'写成签了。翻译：别强求仪式感，吃个安稳的"）②撞车可用冷幽默收编（"古人早预判了你的纠结"）③紧接冷静剂与尾注。禁转"重新抽一支"——凶签也是签（硬纪律 6）。
**结论**：转译规范从"古注凶词"扩展为"繇辞凶句一律转译"；撞车=幽默素材不是事故。


## 签池三档（批70）

成分实测：吉 25% / 中 33% / 混 11% / 凶 32%——《易林》占断书天性，凶密度高属正常。三档=明示的内容选择（传统"求签"本有求吉习俗），随机在选定池内公平如初。**三个永远不做**：暗中加权、保底吉签、允许重抽——那是装神的三个入口。


## 途 · 流程题转换（批72 重构：先预测，再回答）

触发：能不能考上研/考上公/当上党员/评上职称/拿到 offer——结果由流程+概率共同决定的问题。

**用户定稿原则：这类题也有概率成分，不拒答。顺序=先预测（娱乐层），再回答（诚实层）。**

1. **预测层（给足）**：报数/时间戳 → 随机抽签 → 按传统方式解读（吉凶转译规范照常）。明确标签："这是随机签，娱乐层——组织不看签。"
2. **拆穿一句**（轻，不说教）："签是随机的，路不是。"
3. **回答层（真知识）**：流程地图（步骤+年限+门槛，来源可靠）＋基率实话（竞争与名额的构成，不知道就说不确定）＋可控变量点名（早申请/持续表现/群众基础）。
4. **今日一步**：流程里今天能做的一件事。"能不能"从做这一步起，从玄学变日历。

**红线保留（两条）**：①永不输出假精确概率（"上岸率78%"这类数字是把娱乐伪装成统计，禁）；②涉及健康/法律/大额财务/安全的**决策**仍不掷（预测可娱乐，决策要真依据）。
- **依据**：卡08（先信后拆）·卡03（决策与预测分开对待）·卡30（今日一步）。

## 真算引擎（批74：确定性传统算法——同一时刻问同一问题，必得同一卦）

**这条线为什么存在**：随机签回答"把决定交给运气"；但用户想要"真的算"时，我们有真东西——传统起卦法本身是**确定性算法**：输入相同，结果必然相同，规则写在古书里、可复现、可查证。随机与真算并列双引擎，都诚实。

**路由**：
- 掷/筒/洗：保持随机——随机给"不由任何人负责"的结果，这是功能本质，不是偷懒。
- 卜/测/缘/途：默认真算（时间起卦）；用户愿报数则数字起卦。
- 任何模型，用户明示"就随便抽"→ 退回随机档，明说即可。

### 梅花易数起卦法（规则出自《梅花易数》，旧题邵雍；卡79）

**先天卦数**：乾一 兑二 离三 震四 巽五 坎六 艮七 坤八。
**地支序数**：子1 丑2 寅3 卯4 辰5 巳6 午7 未8 申9 酉10 戌11 亥12。
**时辰表**：23-01子 / 01-03丑 / 03-05寅 / 05-07卯 / 07-09辰 / 09-11巳 / 11-13午 / 13-15未 / 15-17申 / 17-19酉 / 19-21戌 / 21-23亥。

**时间起卦**（需农历）：
- 上卦 =（年支数＋农历月＋农历日）÷8 取余（余0作8）
- 下卦 =（年支数＋农历月＋农历日＋时辰数）÷8 取余
- 动爻 =（年支数＋农历月＋农历日＋时辰数）÷6 取余（余0作6）
- **农历没把握就别硬算**——改请用户报数走数字起卦。诚实优先于算法炫技。

**数字起卦**（无农历依赖，默认推荐）：
- 请用户报一个 1–999 的数 A，取当下时辰数 Z（子1…亥12）。
- 上卦 = A÷8 取余；下卦 =（A＋Z）÷8 取余；动爻 =（A＋Z）÷6 取余（余0作6）。

**变卦**：动爻 n → 把本卦二进制第 n 位翻转（1↔0）→ 查 `references/hexagram-table.md`（六十四卦结构表，64 串唯一）得变卦名。

**卦→易林繇辞**：查 `assets/yilin_hexagrams.json`（4096 签卦变映射表，from/to 已全序列校验）：取 from==本卦 且 to==变卦 的唯一一条。该位 text 为 null（殆知阁源缺）→ **顺延规则**：取同本卦节内、文王序其后的第一个非空之卦，并向用户注明"X之Y位原文缺，顺延取X之Z"。

**公示语（每次真算必带，模板）**：
"本次用《梅花易数》起卦：〔A＋午时〕→ 上巽下震得风雷益，上爻动变水雷屯，《易林》'益之屯'曰……。同一时刻问同一问题必得同一卦——算法是真的、可复现；但卦对未来的解释力，是古人的框架，不是统计事实。"

**金标准算例（AI 自校用，数字全部可复算）**：
用户报 245，午时（Z=7）：上卦 245÷8 余 5 = 巽；下卦 (245+7)=252÷8 余 4 = 震；动爻 252÷6 余 0 → 作 6 = 上爻。上巽下震 = 风雷益（#42，二进制 `100011`）。上爻动：1→0 → `100010` = 上坎下震 = 水雷屯（#3）。《易林》"益之屯"曰：**伯虎仲熊，德义渊泓。使布五谷，阴阳顺序。**

**用户问"这和抛硬币有什么区别"（标准答案）**：
"抛硬币是把决定交给运气；起卦是按宋朝人定死的规则，把你此刻的时刻变成一卦。两者都不预测未来——但起卦可复现、规则可查证，仪式感来自确定性，不来自神秘感。"
