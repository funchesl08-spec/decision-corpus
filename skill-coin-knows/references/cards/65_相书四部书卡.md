# 相书四书卡 · 看脸断命运的千年生意，和四库馆臣的"作者打假"

**核心思想（人话版）**：相书是术数里最依赖"第一印象"的门类——和今天的"外貌归因偏见"（看到长相就下判断）完全同构。四库收了四部相书正典，考证出一个共同规律：**几乎每部的"作者"都是假的**。但馆臣照样收——因为他们要的是宋代以前的相法文本，不是神迹。

**读原书读到的四件事**：
1. **托名链条各有破绽**：《太清神鉴》题后周王朴，但自序称"离林屋洞下山三载"——馆臣查王朴生平"游迹未尝一至江左"，**地理对不上**，"其为依托无疑"，且"朴之名则削而不题以袪其伪"。
2. **内.Date error 定案**：《月波洞中记》原序题"赤乌二十年七月"——馆臣照录："赤乌纪号尽十三年，又安得有二十年？明为不学之徒依托附会。"**用年号纪年上限戳穿托名**——和卡19《易林》昭君案同款"教科书级证据"：作伪者不懂他冒充的时代。
3. **门客代笔模式**：《玉管照神局》题宋齐邱——但提要考证他"厚以资之"养了数十个术士门客，"疑即出其门下客所撰集而假齐邱名以行世"——**古代版的"团队出书挂老板名"**。
4. **唯一实名作者**：《人伦大统赋》金·张行简，官至太傅、谥文正，《金史》有传——四库确认这是四部里唯一靠得住的署名，评语"提纲挈领，不三二千言，囊括相术殆尽"。**实名作者往往反而是同类书的顶格水准**（有名誉可担，不敢乱写）。

**真伪分档**：【史实】文本与考据；【无实证】相法断语。
