# 命书六书卡 · 八字是谁发明的？四库馆臣亲自做了一回"起源考证"

**核心思想（人话版）**：今天的"八字"排盘都说源自战国珞琭子、晋代郭璞、唐代李虚中——四库馆臣把这些传说逐一考证后发现：**八字体系出现的时间比所有托名都晚**。提要的铁证照录：韩愈给李虚中写墓志，说他的推命"尚止用年月日，不用时"——**"则开元天宝之间且无八字"**。连李虚中本人都还没用"时辰"，何来祖师爷传下完整八字？

**读原书读到的四件事**：
1. **层累的祖师爷**：《珞琭子三命消息赋注》提要照录——珞琭子被说成周灵王太子晋、又说是陶弘景，但赋中引"悬壶化杖"皆后汉事，"则非周子晋明矣"……结论："**当为北宋人所作，旧称某某皆依托也**"。
2. **四库的"削名袪伪"操作**：《三命指迷赋》"岳珂之名则削除不载焉"；《太清神鉴》"朴之名则削而不题，以袪其伪焉"——**馆臣不只打假，还直接把假作者从书名页上删掉**。四库整理术数=一场文献层面的打假工程。
3. **印度来源不讳言**：《星命溯源》提要引王充《论衡》"天施气而众星布精……"证汉代已有星位言禄命，又引杜牧墓志自占星宫——五星推命（果老星宗）与西域星学的关系提要直言不讳。
4. **馆臣的"部分有效"评法**：《玉照定真经》"所言吉凶应验切近中理亦多有可采……惟推及外亲女婿以曲说穿凿"——**逐条区分"切近中理"与"穿凿附会"**，不是一刀切骂迷信。这种精细化批评本身就是今天的科普该学的姿势。

**真伪分档**：【史实】文献考证；【无实证】禄命推算（含"当代不验"馆臣判词前例）。
