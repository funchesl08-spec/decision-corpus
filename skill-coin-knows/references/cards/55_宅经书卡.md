# 《宅经》书卡 · "人宅相扶，感通天地"——阳宅风水的开山总纲

**核心思想（人话版）**：这是四库术数类"相宅相墓"属的第一部书——托名黄帝，实际是汉唐间作品。它讲阳宅（活人住的房子），比《葬书》讲阴宅更贴近生活；名句"宅以形势为身体，以泉水为血脉"把房子说成了一个活人。

**读原书读到的三件事**：
1. **总纲一句定调**："夫宅者乃是阴阳之枢纽，人伦之轨模"——住宅被抬到"阴阳枢纽"的高度，这是整个阳宅风水的理论起点。
2. **身体喻六连**："宅以形势为身体，以泉水为血脉，以土地为皮肉，以草木为毛发，以舍屋为衣服，以门户为冠带"——把宅拟人化的文学范例，后世所有阳宅话语的模板。
3. **五虚五实清单**："宅有五虚令人贫耗，五实令人富贵"——具体可操作的吉凶判词，与《葬书》五不葬同款"清单体"。
4. **四库考辨有惊喜**：馆臣考证汉隋史志皆不题黄帝，断"是书盖依托也"，但据《宋史·艺文志》推断此书宋代已有，给出**"术数之中犹最为近古"**的定位——托名归托名，古是真古。

**真伪分档**：【史实】托名考辨、二十四路方位体系；【环境内核】采光朝向水源等居住考量；【无实证】门族兴衰感应。
