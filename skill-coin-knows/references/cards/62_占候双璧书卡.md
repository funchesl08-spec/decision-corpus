# 《开元占经》《灵台秘苑》书卡 · 一百万字的"天象-人事"数据库，和一部古佛腹里救出的书

**核心思想（人话版）**：如果古人真建过一个"异常事件→人事解读"的数据库，就是这套书：日食、彗星、风雷、井泉自出、牛马发怪……共120卷、**107万字**，把战国到唐的星占断语全部汇编成检索手册。它占不准，但它是**中国古代"不确定性归因"行为的最大化石标本**——每一卷都在回答"坏事发生了该怪谁"。

**读原书读到的四件事**：
1. **主编是印度裔**：瞿昙悉达出身天竺天文世家，卷一百四整卷收《天竺九执历经》——**唐朝的国家占星手册里内嵌一整套印度历法**，这是中印科学交流的实物证据，比"占"本身有价值得多。
2. **抢救古籍功臣**：提要照录"征引古籍极为浩博，如隋志所称纬书八十一篇，此书尚存其七八，尤为罕觏。然则**其术可废，其书固有可采也**"——术数书提要的最高褒奖：术废书存。
3. **书本身有传奇**：明万历年间此书国内几乎失传，张明哲识语照录——其弟"以布施装金而**得此书于古佛腹中**"，即佛像修复时在腹内藏经中发现。一百万字就这样从"古佛肚子"里回到人间。
4. **《灵台秘苑》的删减史**：庾季才原书115/110卷，宋奉敕删成15卷；朱彝尊跋语照录——"若作酒醴，去其浆而糟醨在矣"（好比酿酒把酒浆去了只剩酒糟）。**官方筛过的占候书=糟粕版**，这个比喻把"知识在删减中失真"说绝了。

**真伪分档**：【史实】文本与流传；【无实证】占验断语。
