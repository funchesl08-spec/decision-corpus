# 六爻四书卡 · 三枚铜钱的操作手册：黄金策用一篇文章统一了整个行业

**核心思想（人话版）**：六爻（摇卦）是今天最活的术数品类——App 摇卦、直播间算卦都从这来。它的技术底座是四部书，而真正的"宪法"只有一篇：《黄金策·总断千金赋》开篇两句——"**动静阴阳，反复迁变。虽万象之纷纭，须一理而融贯**"。万象归一理（五行生克），这句话是整个六爻体系的公理。

**读原书读到的四件事**：
1. **托名照旧**：《黄金策》题刘基（刘伯温）——和卡66《演禽通纂》"举而归之于基"同款操作：**名人=流量，明代术数出版业的标配**。
2. **公理化尝试**：千金赋全文用一套极简符号系统（用神/原神/忌神/仇神 + 生扶拱合/克害刑冲）推演一切问题——**"太过者损之斯成，不及者益之则利"**，这是把占卜改造成类似物理学的均衡论尝试。
3. **出版的力量**：《卜筮全书》27万字是明末书坊刻本（谈易斋重订、金阊翁少麓梓行——**版权页级别的出版信息都在**），"敦请百愚姚先生删繁补缺"——六爻标准化是**商业出版驱动的**，先有教材后有行业。
4. **层累活着**：《断易天机》正文里现代编者"虎易"直接插注："野鹤老人在《增删卜易》中有论六冲，更为合理，附后"——**21世纪的电子版本还在做增删**，这条层累链没有断点。

**真伪分档**：【史实】文本与出版史；【无实证】断法体系。
